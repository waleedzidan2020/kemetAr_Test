# MindAR single-image target

The binary `targets.mind` in this directory contains exactly **one** 720×1280 front-facing photograph of the Zamalek emblem (`targetIndex: 0`). It is byte-for-byte identical to the uploaded `targets2.mind` (SHA256 `6f367c1c009c8f18cc06d5ce8743aba96a8adb0c7f8c99e832392f2e65f2ae85`). This was reconstructed exactly from the fourth image of the previous four-image binary; the matching and tracking payloads were independently confirmed identical before writing it.
